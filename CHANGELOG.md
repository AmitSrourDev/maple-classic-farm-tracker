# Changelog

## 0.3.0 - 2026-11-03
- First installable release: Windows installer (Inno Setup), portable zip, self-update from GitHub Releases.
- Overlay + console front-ends on one engine; settings window (general, pots, meowdb sync, updates); start with Windows.
- EXP/min with a trimmed "farm rate" (idle minutes and arrival bursts excluded), ETA to next level.
- Quickslot potion counts, usage/h and mesos/min; mesos from the inventory window; net mesos/min.
- Per-map grind log (farm EXP/h, pots cost, mesos, net) with map names snapped to the Classic World map list.
- Lucky Seven kill/MP model from a meowdb build export (hit chance, one-cast probability, MP per kill).
- Multi-monitor and windowed-anywhere detection; region pickers for manual overrides.
